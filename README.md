# MuzicMania packages

Repositorios DNF/APT firmados para MuzicMania (launcher nativo Linux).

- `docs/rpm` — repo DNF (Fedora/RHEL/openSUSE)
- `docs/deb` — repo APT (Debian/Ubuntu/Mint)
- `docs/muzicmania.asc` — clave pública de firma

Publicado con GitHub Pages. La clave privada no vive en este repositorio.
