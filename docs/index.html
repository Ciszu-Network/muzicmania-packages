MuzicMania repositorios

Paquetes Linux firmados con la clave muzicmania.asc. Versión actual: Launcher 2.4.2 · Juego 2.1.1 (beta).

Fedora / RHEL / openSUSE

sudo curl -fsSL https://ciszu-network.github.io/muzicmania-packages/muzicmania.asc -o /etc/pki/rpm-gpg/RPM-GPG-KEY-muzicmania
sudo curl -fsSL https://ciszu-network.github.io/muzicmania-packages/rpm/muzicmania.repo -o /etc/yum.repos.d/muzicmania.repo
sudo dnf install muzic-mania

Debian / Ubuntu / Mint

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://ciszu-network.github.io/muzicmania-packages/muzicmania.asc | sudo tee /etc/apt/keyrings/muzicmania.asc >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/muzicmania.asc] https://ciszu-network.github.io/muzicmania-packages/deb ./" | sudo tee /etc/apt/sources.list.d/muzicmania.list
sudo apt update && sudo apt install muzic-mania

Arch Linux

El PKGBUILD está en el repositorio principal, pendiente de publicación en AUR. Mientras tanto:

git clone https://github.com/Ciszu-Network/CiszuNetwork
cd CiszuNetwork/projects/muzicmania/packaging/aur
makepkg -si

Comprobación

rpm --checksig MuzicMania-2.4.2-1.x86_64.rpm
gpg --verify repodata/repomd.xml.asc repodata/repomd.xml
